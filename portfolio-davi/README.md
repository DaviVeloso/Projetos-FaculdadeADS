## Descrição

Landing page de portfólio para apresentar desenhos digitais, com galeria, seção sobre o artista, comissões e formulário de contato. Nesta etapa o site é estático: o formulário ainda não envia mensagens.

## Tecnologias utilizadas até o momento

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`)
- CSS3 próprio, sem framework (Flexbox, Grid, colunas e media queries)

## Responsividade

Testado em três larguras, com media queries em 900px e 600px:

- Desktop: galeria em 3 colunas
- Tablet (até 900px): galeria em 2 colunas
- Celular (até 600px): galeria em 1 coluna

## Como executar

Abra o arquivo `index.html` no navegador. Não precisa de servidor.
